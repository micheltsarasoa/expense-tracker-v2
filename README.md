\# Expense Tracker



A full-stack expense tracking application built with Next.js, PostgreSQL and NextAuth.js.



\## Features



\### Core Functionality

\- 🔐 \*\*Authentication\*\* - Secure login/signup with NextAuth.js

\- 💰 \*\*Transactions\*\* - Track income, expenses, and transfers with labels

\- 🏦 \*\*Accounts\*\* - Multiple payment methods with auto-balance tracking

\- 📊 \*\*Categories\*\* - Organize transactions with custom categories and icons

\- 🏷️ \*\*Labels\*\* - Additional categorization with customizable colors

\- 💸 \*\*Budgets\*\* - Set one-time or recurring budgets with category grouping

\- 📈 \*\*Reports\*\* - Visual analytics with charts and trends

\- 📥 \*\*Import\*\* - Bulk import from CSV/Excel files

\- ⚙️ \*\*Settings\*\* - Customize formatting for numbers, dates, and currency



\### Budget Management

\- 📅 \*\*Smart Period Tracking\*\* - Correct date ranges for weekly/monthly/yearly budgets

\- 📁 \*\*Category Grouping\*\* - Collapsible sections organized by category

\- 🎯 \*\*Progress Monitoring\*\* - Real-time spending vs budget tracking

\- 🏷️ \*\*Label Support\*\* - Budget filtering by transaction labels



\### User Experience

\- 🌙 \*\*Dark Mode\*\* - Toggle between light and dark themes

\- 📱 \*\*Responsive Design\*\* - Works seamlessly on all devices

\- ✏️ \*\*Edit/Delete\*\* - Full CRUD operations on all data

\- 📄 \*\*Pagination\*\* - Efficient browsing of large datasets

\- 🌍 \*\*Localization Ready\*\* - Customizable number and date formats



\### Formatting Customization

\- 💱 \*\*Currency Formatting\*\* - Custom symbols and positioning

\- 🔢 \*\*Number Formatting\*\* - Decimal and thousand separator preferences

\- 📅 \*\*Date Formats\*\* - MM/DD/YYYY, DD/MM/YYYY, YYYY-MM-DD, DD.MM.YYYY

\- ⏰ \*\*Time Formats\*\* - 12-hour (AM/PM) or 24-hour display

\- 🎨 \*\*Live Preview\*\* - See formatting changes before saving





\## Tech Stack



\- \*\*Framework:\*\* Next.js 14 (App Router)

\- \*\*Database:\*\* PostgreSQL (Neon)

\- \*\*Authentication:\*\* NextAuth.js

\- \*\*Styling:\*\* Tailwind CSS + shadcn/ui

\- \*\*Language:\*\* TypeScript

\- \*\*Charts:\*\* Recharts

\- \*\*File Parsing:\*\* PapaParse, SheetJS
