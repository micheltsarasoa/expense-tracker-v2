# Accessibility

- Target WCAG 2.2 AA (D-39).
- Semantic HTML first; ARIA only when no element fits.
- Every control is reachable and usable by keyboard, with a visible focus.
- Every input has a label; every icon-only button has an accessible name.
- Contrast 4.5:1 for text, 3:1 for UI parts; never colour alone to convey meaning.
- Storybook stories run axe (D-32); fix violations, do not disable rules.
