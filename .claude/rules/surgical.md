# Surgical reads and edits

- Locate with Grep or Glob first, then Read only the needed line range.
- Change the minimum that satisfies the task. No reformatting, renaming, reordering or "while I'm here" fixes outside the task; propose them instead.
- Do not create a file unless the task needs it. Prefer editing an existing one.
- Before overwriting or deleting, look at the target.
- One task, one commit, one PR.
