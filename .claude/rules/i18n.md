# Internationalisation

- No hard-coded user-facing string; use translation keys. FR is the default locale, EN required (D-07).
- The child app uses its age-group namespaces (D-23).
- French typography: narrow no-break space before `: ; ! ?` and inside « », `1 234,56 €`, dates `16 nov. 2026`.
- Format money and dates with the locale helpers, never by string concatenation.
